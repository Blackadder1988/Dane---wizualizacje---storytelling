# Datawrapper

Kolekcja wizualizacji danych przygotowanych w Datawrapper.

Folder zawiera projekty związane z analizą danych, data storytellingiem oraz
eksperymentowaniem z różnymi formami wizualizacji.

## Projekty

- **Premier League** — wizualizacje i analizy dotyczące angielskiej Premier League.
- **Klub Języka Danych** — ćwiczenia i prace rozwijające umiejętności wizualizacji oraz storytellingu danych.
